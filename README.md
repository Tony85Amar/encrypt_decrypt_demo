# Encrypt/Decrypt Demo

This project shows simple AES (symmetric) and RSA (asymmetric) encryption using the message:

**"Hello from Tony Whitelow"**

# AES (Symmetric Encryption)
- Uses one key for both encrypt and decrypt.
- Program prints:
  - AES key
  - AES IV
  - Input message
  - Encrypted output
  - Decrypted output

# RSA (Asymmetric Encryption)
- Uses two keys:
  - Public key encrypts
  - Private key decrypts
- Program prints:
  - RSA public key
  - RSA private key
  - Input message
  - Encrypted output
  - Decrypted output
